# SmartPlant AI — M.Tech Artificial Intelligence Research Plan

## Proposed title
Interpretable Lightweight Plant Leaf Disease Classification Using Texture and Color Features: A Reproducible Web-Based Study

## Abstract
This research prototype presents an accessible workflow for plant leaf image analysis. It computes interpretable color indicators and supports a trained Random Forest classifier using Histogram of Oriented Gradients (HOG) texture features and RGB histograms. The web interface enables image upload, model prediction when an independently trained artifact exists, and class probability visualization. No pretrained classifier or validated performance claim is bundled. Future experiments should evaluate disease classification using a properly licensed labeled dataset and independent field imagery.

## Research objectives
1. Build a usable web interface for uploading and processing plant leaf images.
2. Develop an interpretable baseline using HOG features, color histograms and Random Forest.
3. Compare macro F1, precision, recall, and confusion matrices across plant diseases.
4. Study robustness to lighting, background changes and unseen farms.
5. Document training reproducibility and dataset provenance.

## Methodology
- Dataset: collect or obtain licensed leaf photographs with class labels; record license, provenance and crop types.
- Preprocess: EXIF-aware RGB conversion and 128 × 128 resizing.
- Extract: HOG edges, channel histograms, color mean and standard deviation.
- Train: class-balanced Random Forest with fixed seed.
- Validation: current training script uses stratified random 75/25 split, suitable for a baseline only.
- Improved study: use plant/group-aware train-validation-test splits, deduplicate near-identical photos, and include independent field data.
- Metrics: accuracy, macro and weighted F1, per-class precision/recall, confusion matrix and confidence calibration.
- Error analysis: confusion between diseases, lighting, occlusion, crop imbalance and novel classes.

## Threats to validity
PlantVillage-like datasets often contain controlled backgrounds and correlated images. Random image splits may overestimate generalization. Model probabilities are not calibrated. RGB color heuristics are not disease severity estimates. Model predictions should not drive pesticide use without qualified verification.

## Baseline implementation
Run `python train.py --data data/train` after placing labeled images in subfolders. The output is `models/plant_model.joblib` and `models/plant_model.metrics.json`. The model is intentionally not shipped because no specific trained model has been validated.

## Future M.Tech enhancements
Transfer learning (MobileNetV3), Grad-CAM explanations, open-set rejection, group-aware evaluation, camera/domain-shift studies, TensorFlow Lite conversion and on-device benchmarking. These are future research goals, not completed results.
